압축을 풀고 설치해요

시작키트를 내려받아, setup.py가 있는 폴더를 엽니다.

Python 3.10 이상 ↗과 Antigravity ↗를 준비하세요. 실습 폴더의 터미널에서 내 운영체제에 맞는 명령을 실행합니다.

Windows · PowerShell
py -3 setup.py
macOS · Terminal
python3 setup.py

설치 후 확인
실습 폴더에 .venv와 antigravity-config.generated.json이 생깁니다. 설치 스크립트는 앱 설정을 자동으로 덮어쓰지 않습니다. 설치만 끝났다면 아직 국가DB를 조회한 것은 아닙니다.

Antigravity에 설치·시험을 맡기고 싶어요

압축을 푼 실습 폴더를 Antigravity에서 열고 아래 요청을 사용하세요. 키 발급과 키 입력은 본인이 직접 합니다.

설치·모의 시험 요청
내가 연 실습 폴더의 README를 읽고 건축HUB MCP 시작키트의 설치와 모의 시험을 도와줘. Python 3.10 이상인지 확인하고 운영체제에 맞는 setup.py 명령을 설명해 줘. 기존 앱 설정은 자동으로 덮어쓰지 말고 생성된 antigravity-config.generated.json의 연결 항목을 내가 확인하도록 안내해 줘. get_setup_status와 demo_building_lookup으로 설정 상태와 모의 결과를 확인하되 모의를 실제 조회로 표현하지 마. 실제 키는 내가 직접 입력한다. 사용자 홈의 .zeroarchitect/data-go-kr.env를 읽거나 키를 출력하지 말고, 대화창이나 도구 인자에 키를 넣으라고 요구하지 마. 내가 승인 상태와 키 입력을 확인한 뒤에만 lookup_building_title을 사용해 실제 조회를 도와줘.
2

키 없이 모의 시험부터 해요

명령은 모두 압축을 푼 실습 폴더에서 실행합니다.

config --save는 내 폴더에 맞는 MCP 설정 조각을 저장하고, check는 준비 상태를 확인합니다. demo는 고정된 모의 자료를 보여 줍니다. 실제 국가DB 호출이나 실제 건물의 확인 결과로 기록하지 마세요.

Windows · 순서대로 실행
.\.venv\Scripts\python.exe manage.py config --save
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py demo
macOS · 순서대로 실행
.venv/bin/python manage.py config --save
.venv/bin/python manage.py check
.venv/bin/python manage.py demo

이 단계는 설치와 출력 형식의 확인입니다. 키가 ‘설정되지 않음’이어도 모의 시험은 구분해서 진행할 수 있습니다.

3

본인 인증키를 로컬에 등록해요

API 키는 서비스 이용을 위한 비밀값입니다.

  1. 공공데이터포털의 건축HUB 건축물대장정보 서비스 ↗에서 본인 계정으로 활용 신청과 승인 상태를 확인합니다.
  2. 아래 준비 명령이 안내하는 키 파일을 내 컴퓨터의 텍스트 편집기로 엽니다.
  3. DATA_GO_KR_SERVICE_KEY=의 등호 오른쪽에 본인 키를 직접 입력하고 저장합니다. 코드 폴더 바깥의 사용자 홈 파일이며, 제출하거나 GitHub에 올리는 파일이 아닙니다.
Windows
.\.venv\Scripts\python.exe manage.py prepare-key
macOS
.venv/bin/python manage.py prepare-key

기본 키 파일: ~/.zeroarchitect/data-go-kr.env. Windows에서는 사용자 홈 폴더 아래 .zeroarchitect\data-go-kr.env입니다. 준비 명령이 보여 주는 실제 경로를 따르세요.

키 값을 출력해 확인하지 마세요.
check 또는 MCP 도구 get_setup_status에서 키가 설정됐는지만 확인합니다. 실제 키는 MCP 도구의 입력 항목으로 받지 않습니다. 발급·승인이 안 됐다면 미실행 이유를 기록할 수 있습니다.

생성된 설정을 MCP에 연결해요

내 폴더의 실제 경로가 들어 있는 생성 파일을 사용합니다.

antigravity-config.generated.json을 열고, 아래 앱 메뉴에서 확인한 실제 MCP 설정에 새 서버 항목을 추가합니다. 기존에 있던 서버 항목은 보존하세요. 생성 파일에는 실제 키를 넣지 않습니다.

Antigravity App

Customizations → Installed → MCP Servers → Copy Config File Path

표시된 경로의 설정 파일에서 새 서버 항목을 추가합니다.

Antigravity IDE

에이전트 패널의 … → MCP Servers → Manage MCP Servers → View raw config

기존 설정을 통째로 지우지 말고 새 항목을 병합합니다.

저장 후 MCP 연결을 새로고침하거나 앱을 다시 실행하고, 다음 세 도구를 확인하세요. 화면 경로가 다르면 현재 공식 MCP 안내 ↗를 따릅니다.

  • get_setup_status설정 상태 확인. 키의 실제 값은 출력하지 않습니다.
  • demo_building_lookup키 없는 모의 자료. 실제 국가DB 조회가 아닙니다.
  • lookup_building_title본인 키를 사용한 건축HUB 표제부 실제 조회.

도구 목록이 보이는 것은 연결 준비의 확인입니다. demo_building_lookup을 호출해 모의라고 표시되는지 먼저 확인하고, 실제 조회와 구분하세요.

5

공식 자료를 실제로 조회해요

본인 키 등록과 활용 승인 상태를 확인한 뒤 진행합니다.

아래 코드는 공식 문서의 샘플 조회 조건입니다. 시군구 코드 11680, 법정동 코드 10300으로 조회하며 특정 건물이나 응답 성공을 보장하지 않습니다.

Antigravity에서 도구 호출 요청
내가 본인 키를 로컬 파일에 입력했고 활용 승인 상태를 확인했어. lookup_building_title 도구의 입력 형식을 확인한 뒤 시군구 코드 11680, 법정동 코드 10300 조건으로 한 번 조회해 줘. API 키는 요청하거나 출력하지 마. 실제 응답의 상태·조회 조건·출처·조회 시각·건수를 구분하고, 응답에 없는 건물 정보는 만들지 마. 0건이나 오류도 그대로 알려줘.
먼저 터미널에서 API 연결만 시험하고 싶어요

이 명령은 MCP 앱을 거치지 않는 직접 API 시험입니다. 성공해도 ‘MCP 도구 호출까지 성공’했다고 쓰지 말고 실제 실행한 범위를 구분하세요.

Windows
.\.venv\Scripts\python.exe manage.py direct-live --sigungu-cd 11680 --bjdong-cd 10300
macOS
.venv/bin/python manage.py direct-live --sigungu-cd 11680 --bjdong-cd 10300

성공·0건·오류를 다르게 기록해요.
받은 항목·조건·출처·조회 시점을 직접 확인합니다. 대장 정보만으로 실제 현황·구조 안전·법규 적합성을 확정하지 않습니다. 샘플 응답이나 AI가 만든 표를 실제 조회 결과로 대신 쓰지 마세요.

출력의 state 값을 구분해요

상태 표시는 실행 범위를 보여 줍니다. key_configured: true는 키가 설정돼 있다는 뜻이며 유효성·활용 승인·조회 성공의 증거가 아닙니다.

setup_check설치와 키 존재만 확인했습니다. 국가DB 조회 성공이 아닙니다.
setup_required키 등 준비가 필요합니다. 실제 조회에 성공한 결과로 쓰지 않습니다.
demo명백한 모의 자료입니다. 실제 국가DB를 조회하지 않았습니다.
live실제 국가DB 응답의 자료를 받았습니다. 반환된 항목과 확인한 범위만 기록합니다.
no_data해당 조회 조건의 응답이 0건입니다. 전체 자료가 없다고 단정하지 않습니다.
error오류가 발생했습니다. 성공 자료로 대체하지 말고 오류와 다음 확인을 기록합니다.

내가 확인한 범위를 기록해요

처음 열어 둔 실습 홈페이지 탭의 11번 기록칸으로 돌아갑니다.

실행실제로 확인한 범위를 적습니다. API 직접 시험과 MCP 도구 호출을 구분하고, 조건·결과·오류·한계를 남깁니다.
모의demo 또는 연결 설계만 확인했다면 모의라고 밝힙니다. 실제 국가DB 응답을 받은 것으로 쓰지 않습니다.
미실행키·권한·설치·환경 때문에 실행하지 못한 이유와 수동 대안, 다음 확인을 적습니다.

문제 → 연결 대상·입출력·권한 → 작은 검증 또는 대안 → 나의 판단 순서로 기존 기록칸을 채웁니다. 확인하지 못한 부분은 ‘미확인’으로 남겨도 됩니다. 선택 이미지는 키와 개인정보를 지운 뒤 보관하세요.

키가 붙은 요청 URL 전체, 설정 파일, 터미널 로그는 제출하지 마세요. 근거에는 키 없는 공식 문서 링크와 실제로 확인한 내용만 적습니다.

11번은 정규 등급과 별도입니다. 실제 연결이 어려워도 모의·미실행 이유와 대안을 기록할 수 있습니다. 작성 완료 표시는 연결의 진위나 정규 성적을 인증하지 않습니다. 다른 업무·학습·연구 문제를 골라도 됩니다.

여기서 막혔나요?

Python 또는 설치 명령을 찾을 수 없어요

Python 3.10 이상이 설치됐는지, setup.py가 있는 폴더의 터미널인지 확인하세요. 운영체제에 맞는 위 명령을 사용하고 실제 오류를 기록합니다.

MCP 도구 목록이 보이지 않아요

생성된 설정의 경로가 지금 실습 폴더인지 확인하고, 앱에서 실제 설정 위치를 다시 확인하세요. 기존 서버 항목을 보존한 뒤 연결을 새로고침합니다. 키를 대화창에 보내지 마세요.

키 또는 권한 오류가 나요

본인 계정의 건축HUB 활용 신청·승인 상태와 키 파일 위치를 확인하세요. 키는 로컬에서 직접 수정하고, 로그에 나온 전체 요청 URL이나 인증키를 복사해 보내지 마세요. 해결되지 않으면 미실행 사유로 구분합니다.

조회 결과가 0건이거나 네트워크 오류가 나요

정상 0건인지 오류인지 먼저 구분하고 조회 조건·응답 상태·시점을 확인하세요. 다른 페이지나 조건을 검토하지 않았다면 전체 자료가 없다고 단정하지 않습니다. 오류를 모의 성공으로 바꾸지 마세요.

Antigravity 사용량 한도에 도달했어요

앱의 사용량과 갱신 안내를 확인하세요. 공공데이터 인증키를 넣는다고 Antigravity의 AI 한도가 늘어나는 것은 아닙니다. 터미널 직접 시험만 했다면 그 범위로 기록하거나, 모의·미실행으로 남길 수 있습니다.

공식 자료 확인: 2026-11-16. 설치·모의 시험과 실제 인증 조회는 별개이며, 이 안내는 본인 키로 실제 조회에 성공했다고 주장하는 자료가 아닙니다. Antigravity 앱 화면 연결과 본인 키를 쓴 국가DB 실조회는 제작 단계에서 아직 검증하지 않았습니다.
